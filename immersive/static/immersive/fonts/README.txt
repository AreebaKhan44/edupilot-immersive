Noto Naskh Arabic (Regular + Bold) - SIL Open Font License 1.1, (c) The Noto Project Authors.
Used to draw Urdu / Arabic text inside generated pictures, slides and videos, and in the 3D viewer.
To use a different Urdu font (e.g. Jameel Noori Nastaleeq), copy its .ttf here: a file whose name contains
"noori", "nastal", "naskh", "urdu" or "jameel" is picked first (a "Bold" file is used for headings).
